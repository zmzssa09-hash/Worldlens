# WorldLens — 세상의 조각들을 연결하다

여러 나라 언론의 세계 뉴스를 모아 **사건별로 묶고**, 나라마다 어떻게 보도하는지 **나란히 비교**해 보는 서비스의 MVP입니다.

## 실행하기

Node.js 22.13 이상이 필요해요 (지금 컴퓨터에는 24가 설치돼 있어요).

```bash
cd worldlens
npm install      # 처음 한 번만
npm start
```

브라우저에서 **http://localhost:3000** 을 열면 돼요. 처음 켜면 30초쯤 뉴스를 모은 뒤 화면이 채워져요.
끄려면 터미널에서 `Ctrl + C`를 누르세요.

## 데모 모드와 AI 모드

| | 데모 모드 (기본) | AI 모드 |
|---|---|---|
| 조건 | API 키 없음 | `.env`에 `ANTHROPIC_API_KEY` 있음 |
| 뉴스 수집·사건 묶기 | ✅ 실제 뉴스 | ✅ 실제 뉴스 |
| 기사 제목·요약 | 한국어 자동 번역 | 한국어 자동 번역 |
| 사건 제목 | 대표 기사 제목(번역) | Claude가 쓴 쉬운 한국어 제목 |
| 사실·관점·가설·스토리 | 번역된 기사 요약을 정리한 형식 예시 | Claude가 분석 |

### AI 모드 켜기
1. https://console.anthropic.com 에서 API 키를 만들어요.
2. `.env.example` 파일을 복사해 이름을 `.env`로 바꾸고, `ANTHROPIC_API_KEY=` 줄의 `#`을 지운 뒤 키를 붙여 넣어요.
3. 서버를 다시 시작해요. 화면 위 상태 표시가 **AI 분석**으로 바뀌면 성공이에요.

**비용 안내:** 기본 모델은 `claude-opus-5-5`예요. 비용 안전장치는 아래 "실시간 업데이트"를 보세요. 더 아끼고 싶다면 `.env`에서 `WORLDLENS_MODEL=claude-sonnet-5-5`(또는 `claude-haiku-5-5`)로 바꾸거나 `WORLDLENS_MAX_AI_EVENTS`를 낮추세요.

## 실시간 업데이트
- **5분마다** 16개 매체에서 새 기사를 모으고, 사건에 이어 붙이고, 번역하고, 필요한 사건을 분석해요.
- 화면은 **새로고침하지 않아도 저절로 바뀌어요.** 서버가 새 소식을 브라우저에 바로 알려 줘요(`/api/stream`, Server-Sent Events). 새 기사가 들어오면 화면 아래에 알림이 잠깐 떠요.
- 화면 위의 빨간 **실시간** 표시는 서버와 실시간 연결이 살아 있다는 뜻이에요.
- 매일 아침 7시에 오늘의 세계 브리핑을 새로 만들어요.
- 간격은 `.env`의 `WORLDLENS_LIVE_CRON`(기본 `*/5 * * * *`)으로 바꿀 수 있어요.

서버가 켜져 있는 동안에만 업데이트돼요.

### AI 비용 안전장치
5분마다 돌기 때문에, AI 분석이 너무 자주 돌지 않도록 제한을 걸어 두었어요.

| 설정 (`.env`) | 기본값 | 뜻 |
|---|---|---|
| `WORLDLENS_MAX_AI_EVENTS` | 4 | 한 번 갱신할 때 AI로 분석하는 최대 사건 수 |
| `WORLDLENS_MAX_AI_PER_DAY` | 120 | 하루 최대 AI 분석 횟수 (넘으면 다음 날까지 멈춤) |
| `WORLDLENS_REANALYZE_MINUTES` | 60 | 같은 사건을 다시 분석하기까지 최소 간격 (새 기사 2건 이상 + 이 시간 경과) |

처음 등장한 사건은 바로 분석하고, 이미 분석한 사건은 위 조건을 만족할 때만 다시 분석해요.

## 회원·구독 (유료 기능)
| | 비회원 | 무료 체험 (가입 후 7일) | 구독 회원 |
|---|---|---|---|
| 뉴스·브리핑·확인된 사실·3분 스토리·타임라인 | ✅ | ✅ | ✅ |
| **나라별 관점** | 🔒 | ✅ | ✅ |
| **가설** | 🔒 | ✅ | ✅ |

- 잠긴 내용은 **서버가 아예 보내지 않아요.** 화면에서 가리기만 하면 개발자 도구로 보이기 때문이에요. 몇 개가 준비돼 있는지만 알려 줘요.
- **결제 흐름:** 가입 → 7일 무료 체험 → 카드 등록(토스 자동결제) → 체험이 끝나는 날 첫 결제 → 매달 자동 결제.
  - 체험 중에 해지하면 결제되지 않아요.
  - 구독 중에 해지하면 그달 끝까지 볼 수 있어요.
- **정기 결제:** 토스는 정기 결제 일정을 대신 돌려주지 않아요. 이 서버가 10분마다 결제일이 된 회원을 찾아 결제해요(`src/billing.js`의 `runRenewals`). **서버가 꺼져 있으면 정기 결제도 멈춰요.**
- **토스 키가 없을 때:** '개발용 테스트 결제' 버튼으로 결제 없이 구독 처리돼요. 실제 서비스 전에 `WORLDLENS_DEV_BILLING=off`로 꼭 끄세요.

### 실제로 돈을 받기 전에 필요한 것
1. **토스페이먼츠 가입 → 테스트 키로 시험:** 자동결제는 테스트에서도 '자동결제 계약된 상점 키'가 필요할 수 있어요. 키를 넣고 카드 등록이 `NOT_SUPPORTED_METHOD` 오류로 막히면 토스에 문의하세요.
2. **자동결제 계약:** 토스 자동결제는 추가 심사와 계약을 거쳐야 실제로 쓸 수 있어요. 국내 발급 카드만 돼요.
3. **사업자등록, 통신판매업 신고.**
4. **이용약관, 개인정보처리방침, 환불 정책 페이지와 사업자 정보 표시:** 정기 결제 서비스라면 사실상 필수예요. 아직 없어요.
5. **인터넷 배포 + HTTPS:** 로그인 쿠키와 결제 창이 안전하게 동작하려면 필요해요.

## 구조

```
server.js              웹 서버 + API
src/sources.js         언론사 목록 (나라·지역·국영 여부)
src/collector.js       RSS 수집·정리
src/translator.js      기사·분석 자동 번역 (5개 언어)
src/clusterer.js       기사를 사건으로 묶기 (핵심어 겹침 + 비슷한 사건 합치기)
src/analyzer/          분석기 (claude.js = AI, demo.js = 데모, prompts.js = 중립성 원칙)
src/pipeline.js        수집 → 묶기 → 분석 → 브리핑
src/scheduler.js       자동 업데이트·정기 결제 일정
src/auth.js            회원가입·로그인 (scrypt 비밀번호, 세션 쿠키)
src/billing.js         구독·토스 자동결제·정기 결제
public/                화면 (index = 홈, event = 사건 상세, about = 서비스 소개, i18n.js = 화면 문구 5개 언어)
data/worldlens.db      수집한 데이터 (자동 생성, 지워도 다시 모아요)
```

### API
- `GET /api/status` 상태 (모드, 기사 수, 마지막 갱신)
- `GET /api/briefing` 오늘의 브리핑
- `GET /api/events?region=asia` 사건 목록 (지역: asia, europe, middle-east, americas, africa, oceania, global)
- `GET /api/events/:id` 사건 상세 (분석 + 기사 타임라인)
- `POST /api/refresh` 지금 갱신

## 언론사 추가하기
`src/sources.js`에 한 줄을 추가하면 돼요. RSS 주소가 동작하는지 먼저 확인하세요.

## 5개 언어 지원
화면 오른쪽 위에서 **한국어 · English · 日本語 · 中文 · Français**를 고를 수 있어요. 고른 언어는 브라우저에 기억되고, 주소 뒤에 `?lang=ja`처럼 붙여 바로 열 수도 있어요.

| 무엇을 | 어떻게 번역하나 |
|---|---|
| 메뉴·버튼·안내문 (`public/i18n.js`) | 미리 번역해 둔 문구 |
| 서비스 소개 페이지 (`public/about-content.js`) | 미리 번역해 둔 글 |
| 기사 제목·요약 | 수집할 때 자동 번역 (원문이 영어라 영어는 그대로) |
| AI 분석·브리핑 | 한국어로 한 번 분석한 뒤 다른 언어로 자동 번역 → 언어가 늘어도 AI 분석 비용은 그대로 |

**자동 번역 방식** (`src/translator.js`)
- **API 키가 있으면:** Claude Haiku(`claude-haiku-5-5`)로 번역해요. 안정적이고, 하루 비용은 수십 원 수준이에요. 모델은 `WORLDLENS_TRANSLATE_MODEL`로 바꿀 수 있어요.
- **키가 없으면:** 무료 Google 번역 주소를 써요. 공식 API가 아니라 요청이 많으면 한동안 막혀요(HTTP 429). 그래서 화면에 나오는 기사만, 한 번에 언어당 60건씩 천천히 번역하고, 막히면 30분 쉬었다가 다음 갱신 때 이어서 해요. 번역 전까지는 영어 원문이 보여요.
- 번역을 끄려면 `.env`에 `WORLDLENS_TRANSLATE=off`를 넣으세요.

## 알려진 한계 (MVP)
- 각국 매체의 영어판을 수집해 번역해요. 자국어판 매체 추가는 다음 단계예요.
- 새 문구를 화면에 추가할 때는 `public/i18n.js`의 다섯 언어에 모두 넣어야 해요.
- 자동 번역이라 문장이 어색하거나 인명 표기가 틀릴 수 있어요.
- 사건 묶기는 단어 겹침 방식이라 가끔 다른 사건이 섞이거나 같은 사건이 나뉠 수 있어요. AI 모드에서는 분석할 때 관계없는 기사를 걸러내요.
- 기사 전문은 저장하지 않고 제목·요약·링크만 보여 줘요.
